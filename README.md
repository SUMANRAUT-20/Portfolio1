<h1 align="center">ポートフォリオサイト</h1>

<p align="center">
  ラウト・スマンの個人ポートフォリオサイトです。
</p>

## 概要

自己紹介、スキル、制作プロジェクト、趣味、お問い合わせ情報を掲載しています。  
スマートフォン、タブレット、パソコンに対応したレスポンシブデザインです。

## 主な内容

- 自己紹介
- スキル・経験
- 制作プロジェクト
- 趣味（写真撮影・料理）
- お問い合わせ
- レスポンシブ対応
- 写真の自動スライドショー

## 使用技術

- HTML
- CSS
- JavaScript

## 実行方法

1. このリポジトリをダウンロードまたはクローンします。

<pre>
git clone https://github.com/SUMANRAUT-20/Portfolio1.git
</pre>

2. プロジェクトフォルダを開きます。

<pre>
cd Portfolio1
</pre>

3. `index.html` をブラウザで開きます。

VS Codeを使用する場合は、Live Serverでも実行できます。
